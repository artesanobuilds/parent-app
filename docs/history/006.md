# 006: Branding pass, launch screen, and UI refresh

**Date:** December 28, 2025  
**Objective:** Apply the new Sway visual identity (coral/navy on soft-cream), add a branded launch screen, and refresh chat UI elements to match the palette.

## Decisions
- Introduced a centralized brand palette (coral primary, navy text, soft-cream background) and kept light mode as the default.
- Adopted an asset-based launch screen using the provided `launch-screen-1242x2688.png`.
- Simplified resource management by relying on Xcode’s auto-managed resources (removed manual duplicate entries that caused storyboard link conflicts).

## Implementation
- iOS styling:
  - Added `Colors.swift` with `brandCoral`, `brandNavy`, `brandBackground`, `brandSurface`, `brandStroke`.
  - Updated `ChatView` to use brand background, coral accents, navy text; refreshed bubbles (assistant on light surface, user coral with white text), custom send button, and nav bar tint.
  - Forced light appearance in `ContentView` to keep the cream backdrop consistent.
- Launch screen:
  - Created `LaunchScreen.storyboard` and `LaunchScreen.imageset` using `launch-screen-1242x2688.png`.
  - Set `INFOPLIST_KEY_UILaunchStoryboardName = LaunchScreen` and disabled autogenerated launch screen generation.
- Build fixes:
  - Removed manual resource entries that duplicated storyboard linking and produced “Multiple commands produce … LaunchScreen.storyboardc”.

## Testing
- Visual checks on iOS simulator after styling and launch screen changes.
- Clean build after removing duplicate resource entries. No automated tests.
