# 003: iOS Chat Client with Streaming Agent & Markdown UI

**Date:** December 28, 2025  
**Objective:** Add a chat experience to the `sway` iOS app that talks to the FastAPI/LangGraph backend via SSE, with configurable server settings, threaded conversations, auto-scroll, and rich Markdown rendering.

## Context & Constraints
- Mobile client in `sway/` (SwiftUI). Backend in `sway-backend/` (FastAPI, SSE at `/chat`, JSON tokens inside `data:` lines, `[DONE]` terminator).
- Simulator must hit the host via `http://127.0.0.1:8000`; device must use host LAN IP. ATS relaxed to allow HTTP.
- Streaming content arrives token-by-token; needs incremental UI updates.
- Markdown content (headings, lists, blockquotes, tables, code) should render nicely on-device.

## Decisions
1) **Networking & threading:**  
   - `ChatService` uses `URLSession.bytes` to stream SSE, filters `data:` lines, parses JSON `{type:"token",content:"..."}`, stops on `[DONE]`, surfaces status errors.  
   - `ChatViewModel` owns messages, streaming state, errors, and thread reset; uses persisted `thread_id`.

2) **Server configuration & persistence:**  
   - `ServerConfiguration` stores `baseURLString` and `threadID` in `UserDefaults`; provides `resetThread()`.  
   - Settings sheet allows editing base URL and thread ID.

3) **UI & UX:**  
   - `ChatView` with message list, bubbles, send bar, server settings sheet, reset conversation.  
   - Auto-scroll only while the latest assistant message is streaming; user can scroll freely after completion.  
   - Bubbles show streaming spinner on in-flight assistant messages.

4) **Markdown rendering:**  
   - Adopted `MarkdownUI` (SPM) for full Markdown support (headings, lists, blockquotes, tables, code).  
   - Removed prior AttributedString/regex hacks; now render raw message content with MarkdownUI.

5) **App Transport Security:**  
   - ATS set to allow arbitrary HTTP loads so `http://127.0.0.1:8000` works in development.

## Implementation Steps (iOS)
- Added models/services/view model: `ChatMessage`, `ServerConfiguration`, `ChatService`, `ChatViewModel`.
- Built UI: `ChatView`, `ServerSettingsView`; wired `SwayApp`/`ContentView` to start on `ChatView`.
- Integrated MarkdownUI via SPM in `Sway.xcodeproj` and rendered bubbles with `Markdown`.
- Adjusted auto-scroll logic to only follow the stream while active.
- Removed temporary debug logging of raw markdown after verification.

## How to Run
1) Backend (from `sway-backend/`):  
   ```bash
   uvicorn app.server:app --reload --host 0.0.0.0 --port 8000
   ```
2) iOS app (from Xcode): open `sway/Sway.xcodeproj`, select a simulator, run.  
   - In-app “Server” settings: set Backend to `http://127.0.0.1:8000` (simulator) or `http://<your-mac-ip>:8000` (device).  
   - Optional: reset thread ID to start a fresh conversation.
