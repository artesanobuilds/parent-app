# 004: Prompt Refinement & Chat UI Density Tweaks

**Date:** December 28, 2025  
**Objective:** Align the Sway system prompt with GPT-5.2 prompting guidance and improve chat UI density by widening bubbles and reducing font size.

## Decisions
- **System prompt (backend):**  
  - Reworked the agent prompt to emphasize concise, bullet-first responses, explicit ambiguity handling without over-questioning, citation of time-sensitive web facts with dates, and grounding in Jung/Becky Kennedy/Gabor Mate/Daniel Amen.  
  - Added formatting constraints (short sections, avoid long paragraphs) and a self-check list to keep outputs tight and on-tone.
- **Chat UI density (iOS):**  
  - Widened chat bubbles to ~90% of screen width and trimmed horizontal padding to better use screen real estate.  
  - Reduced Markdown font size for messages to 15pt for denser reading.

## Implementation Notes
- Backend prompt: updated `sway-backend/app/agent.py` system prompt block.  
- iOS UI: updated `sway/Sway/ChatView.swift` bubble width, padding, and markdown font size.

## Testing
- No automated tests run (prompt and UI layout tweaks only). Visual check on simulator for layout density.
