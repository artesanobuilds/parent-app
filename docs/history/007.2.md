## Decisions
- **Railway over self-host.** Deploy `mvp-backend` to Railway with a multi-stage Dockerfile (Node stage builds the CMS frontend, Python stage runs FastAPI). Public URL: `https://mvp-backend-production-8678.up.railway.app`.
- **Persistent volume + parquet seeding.** Mount Railway volume at `/app/data/`. `entrypoint.sh` seeds missing or stale parquet files from `/app/seed-data/` (baked into the image), then deletes the `.duckdb` so the app bootstraps from parquet every time. Seed comparison uses file size — if the baked seed is larger than the volume copy, it replaces it.
- **`#if DEBUG` toggle for backend URL.** `ServerConfiguration.swift` auto-selects `localhost:8904` for Xcode/debug runs and the Railway URL for Archive/TestFlight. Manual override via `ServerSettingsView`'s Local/Production segmented toggle.
- **Internal-only TestFlight first.** App Store Connect (Apple ID `6761160877`), bundle `MVP.MVParent`, internal testing group **POC**. No external review yet.

## Implementation

### Backend deploy
- `mvp-backend/Dockerfile` — multi-stage (Node → Python).
- `mvp-backend/railway.toml` — `healthcheckTimeout: 300` (langchain + duckdb imports are slow).
- `mvp-backend/.dockerignore`, `.python-version`, `entrypoint.sh` added.
- Env vars set via `railway variables set`: `OPENAI_API_KEY`, `OPENAI_MODEL_NAME`, `TAVILY_API_KEY`.

### Gotchas resolved (logged in `deployment_railway.md`)
- `railway up` respects `.gitignore`: the original `.gitignore` excluded `data/` wholesale, so parquet seeds never uploaded. Fixed by ignoring only `*.duckdb`, not the directory.
- Healthcheck timeout had to be raised to 300s — uvicorn took >60s to import.
- `CMD` in Dockerfile must be **shell-form** so `$PORT` expands at runtime (Railway injects `PORT=8080`).
- Volume mount over `/app/data/` hides files from `COPY . .`, so seed parquet files have to be copied to `/app/seed-data/` during build and copied into the volume by `entrypoint.sh`.

### iOS TestFlight upload
- Issues that caused builds to silently disappear from App Store Connect:
  - **SVG app icon rejection (ITMS-90013).** Apple requires a 1024×1024 PNG; SVG submissions fail and the rejection email goes to the account email, not Xcode. Converted to PNG on 2026-03-27.
  - **Missing export compliance.** Without `ITSAppUsesNonExemptEncryption = false` in Info.plist, builds get stuck in "Missing Compliance" and stay invisible in TestFlight. Added the key (app uses only standard HTTPS).
- Got to v1.1 build 5 by 2026-03-27.

### Sync workflow
- `tools/sync-data.sh` pulls production parquet files locally, rebuilds the local DuckDB, writes an audit log to `data/.sync-audit.log`. Uses `/data/export` (checksums) + `/data/download/{filename}`. `--watch` syncs every 30 min.
