# 002: Backend Initialization - LangGraph ReAct Agent

**Date:** December 28, 2025
**Objective:** Establish a Python-based backend using LangGraph to serve a conversational ReAct agent with streaming capabilities.

## Context & Constraints
- **Goal:** Create a backend service that an iOS app (`sway`) or web client can interact with.
- **Tech Stack:** 
  - **Language:** Python 3.11+
  - **Frameworks:** FastAPI (Server), LangGraph (Agent Orchestration), LangChain (LLM Utilities).
  - **LLM:** OpenAI (GPT-4o/5.2)
  - **Tools:** Tavily (Web Search)
- **Requirement:** The backend must support **streaming** responses (SSE) for a responsive chat experience.

## Decisions
1.  **Architecture:** Adopted a **ReAct** (Reason + Act) pattern using `LangGraph`. This allows the agent to reason about user inputs, decide to use tools (like web search), and then generate a response.
2.  **Streaming:** Selected **Server-Sent Events (SSE)** over WebSockets. SSE is simpler, firewall-friendly, and sufficient for typical chat interfaces where the server streams text to the client.
3.  **Library Choice:**
    -   Used `langchain.agents.create_react_agent` after discovering deprecation warnings for `langgraph.prebuilt.create_react_agent` in favor of the LangChain 1.0+ patterns.
    -   Integrated `langchain-tavily` and `langchain-agents-pip` to resolve dependency and import issues with the latest library versions.

## Implementation Steps
1.  **Environment Setup:**
    -   Created `sway-backend/` directory.
    -   Defined dependencies in `requirements.txt` (including `fastapi`, `uvicorn`, `langgraph`, `langchain-openai`, `tavily-python`).
    -   Configured environment variables in `env.example` (`OPENAI_API_KEY`, `TAVILY_API_KEY`).

2.  **Agent Logic (`app/agent.py`):**
    -   Initialized `ChatOpenAI` (configurable model name).
    -   Set up `TavilySearchResults` as a tool for real-time web information.
    -   Implemented a persistent-ready `MemorySaver` for conversation state.
    -   Built the agent graph using `create_react_agent`.

3.  **API Server (`app/server.py`):**
    -   Created a FastAPI application.
    -   Implemented `POST /chat` endpoint.
    -   Used an async generator to stream events from `agent.stream()`, transforming them into SSE format (`data: ...`).
    -   Enabled CORS to allow access from local web/mobile clients during development.

## How to Replicate / Run
1.  **Navigate:** `cd sway-backend`
2.  **Install:** 
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    ```
3.  **Configure:** Copy `env.example` to `.env` and add your API keys.
4.  **Run:** 
    ```bash
    uvicorn app.server:app --reload
    ```
5.  **Test:** Send a POST request to `http://localhost:8000/chat` with a JSON body `{"message": "Hello"}` (or use a curl command to see the stream).
