# 001: Project Initialization - Sway iOS App

**Date:** December 28, 2025
**Objective:** Create a barebones Hello World Swift app for the `sway` iOS client.

## Context & Constraints
- **Goal:** Initialize the iOS application under the `sway/` directory.
- **Constraints:** 
  - User has Xcode installed.
  - User does **not** have a paid Apple Developer Program membership.
  - **Impact:** TestFlight distribution is not possible.

## Decisions
1.  **Deployment Strategy:** Since TestFlight is unavailable, we opted for:
    -   **Simulator Testing:** For rapid development.
    -   **Local Physical Device Install:** Using a Personal Team (Apple ID). This creates a provisioning profile valid for 7 days, after which the app must be rebuilt/re-installed.

2.  **Project Creation:**
    -   The Xcode project (`.xcodeproj`) was created manually by the user to ensure proper structure and signing settings, as programmatic generation (via tools like xcodegen) was skipped for simplicity.

## Implementation Steps
1.  **Directory Setup:** The project resides in `sway/Sway`.
2.  **Code Injection:** 
    -   We replaced the default generated files with a clean SwiftUI implementation.
    -   `SwayApp.swift`: Simplified application entry point.
    -   `ContentView.swift`: Basic view displaying "Hello, world!" and a globe icon.

## How to Replicate / Run
1.  **Open Project:** Open `sway/Sway/Sway.xcodeproj` in Xcode.
2.  **Select Target:** Choose a Simulator (e.g., iPhone 16 Pro) or a connected physical iPhone.
3.  **Physical Device Setup (If applicable):**
    -   Select your Personal Team in **Signing & Capabilities**.
    -   On the device, go to **Settings > General > VPN & Device Management** and trust your developer profile.
4.  **Run:** Press `Cmd + R` to build and launch the app.
