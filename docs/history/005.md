## 005: Per-user memory, personalization, and memory dump endpoint

**Date:** December 28, 2025  
**Objective:** Scope chat memory per user + thread, personalize the agent by user name, add a memory dump endpoint, and prompt iOS users for a username each session.

### Context
- Memory was previously keyed only by `thread_id`; no per-user isolation or personalization.
- Needed an easy way to inspect in-memory conversations per user.
- iOS client should collect a username each session (not persisted) and pass it to the backend.

### Decisions
- **Per-user memory key:** Use `user_id:thread_id` for LangGraph `MemorySaver` to isolate conversations.
- **Personalized prompt:** Build per-user agent system prompt (cached) in `app/agent.py`, injecting the user name.
- **Memory dump:** Add `GET /memory/{user_id}` to return all threads/messages for that user from in-memory log.
- **iOS username gating:** Prompt on app launch; block send until provided; default backend `user_id` is `"0"` if absent.

### Implementation
- Backend: `app/server.py`
  - Accepts `user_id` in `ChatRequest` (default `"0"`), builds memory key `user_id:thread_id`.
  - Logs streamed conversations in-memory; buffers assistant content before storing.
  - New endpoint `GET /memory/{user_id}` dumps all threads for that user.
- Backend: `app/agent.py`
  - `_build_system_prompt(user_name)` includes personalization; `get_agent(user_name)` caches per-user agent.
- Docs: `sway-backend/README.md`
  - Added `user_id` to chat payload examples and documented `GET /memory/{user_id}` (curl).
- iOS: `ChatView`, `ChatViewModel`, `ChatService`
  - Session-only username prompt; disables input until set.
  - Sends `user_id` alongside `thread_id` in chat requests.

### Usage snippets
- Chat (SSE):
  ```bash
  curl -N -H "Content-Type: application/json" \
    -d '{"message":"Hi","thread_id":"demo","user_id":"alice"}' \
    http://localhost:8000/chat
  ```
- Dump memory:
  ```bash
  curl http://localhost:8000/memory/alice
  ```

### Testing
- Manual: Verified streaming and memory log population; exercised `/memory/{user_id}` via curl. No automated tests.
