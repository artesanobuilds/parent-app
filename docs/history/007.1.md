# 007.1: Rebrand to MVP, content library, and SchoolMom redesign

**Date:** February 17–22, 2026
**Objective:** Rebrand the app from Sway to MVP (Most Value Parent), ship a real content library backed by DuckDB, redesign Home and Library, and add a community ("Circle") tab.

> Reconstructed from `git log` (commits `0d7b3dc` → `9eaca90`) and memory (`patterns.md`, `architecture.md`, `feedback_app_name.md`). Most work in this window landed across a small handful of squashed commits, so file/line specifics are inferred from the current codebase rather than per-commit diffs.

## Decisions
- **Rename Sway → MVP** ("Most Value Parent"). All copy, icon, bundle name aligned. Sway is no longer a valid reference anywhere in the codebase.
- **Move content from local JSON to DuckDB.** `MockContentProvider.swift` + `content_library.json` (45 articles, 20 community posts, 10 categories) replaced by API-driven `ContentService` + `ContentViewModel`. DuckDB tables `categories` / `articles` / `community_posts` bootstrap from parquet snapshots in `data/`.
- **Rebrand visual to "SchoolMom" aesthetic.** Coral/cream from 006 replaced with the dark-theme palette in `Colors.swift` (`brandBackground`, `brandGold`, `brandNavy`, `brandStroke`, etc.) used across all later work.
- **Article detail is a real screen.** Tapping a card now navigates to a SwiftUI detail view that renders full markdown body via MarkdownUI, fetched from a new `/content/articles/{id}` endpoint that returns the `content` field (list endpoints omit it for performance).
- **Community as a first-class tab.** Circle (community) tab replaces what used to be a single agent surface. Filterable by category.
- **API-prefixed iOS models.** New Codable types `APICategory`, `APIArticle`, `APICommunityPost` distinguish the API layer from the previous local types.

## Implementation
- **Backend:**
  - `app/content.py` — DuckDB-backed content service; explicit `content.init(storage)` call in `server.py` (no auto-load from JSON).
  - `app/duckdb_storage.py` — schema for content tables (`TEXT[]` tags, `ILIKE` search).
  - `migrate_content_to_duckdb.py` — idempotent migration script (`DELETE` before `INSERT`); exports parquet snapshots used for bootstrap on fresh DB.
  - Endpoints added: `/content/categories`, `/content/articles`, `/content/articles/{id}`, `/content/community`, `/content/community/{id}`, `/content/community/{id}/replies`, `/content/search`, `/content/relevant`.
- **iOS:**
  - New tab bar: Home, Library, MVP (agent), Circle.
  - `ContentViewModel` (@MainActor) replaces `MockContentProvider`; `.environmentObject` injection.
  - `ContentService` — static `async`/`await` API calls; independent fetches use separate `do/catch` (not `async let`) for resilience.
  - `HomeView` uses `.navigationBarHidden(true)` + custom greeting header; Library/Circle use inline title.
  - `ContentStore.swift` — typed `ArticleRoute` / `PostRoute` for `NavigationStack`; `.withContentNavigationDestinations()` modifier added to any view that needs detail navigation.
  - `MockContentProvider.swift` and `content_library.json` deleted (visible as `D` in current git status).
  - ATS disabled (`NSAllowsArbitraryLoads = YES`) so debug builds can hit `http://localhost:8904`.

## Testing

- Migration verified by running `migrate_content_to_duckdb.py` and confirming 75 items (10 + 45 + 20) load.
