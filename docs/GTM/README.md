# Go-To-Market (GTM)

The workspace for MVP's go-to-market strategy — positioning, audience, channels,
pricing, and launch. Product/engineering docs stay in `docs/` (see `roadmap.md`,
`system-architecture.md`); this folder is deliberately separate so GTM can move on
its own track.

## What's here

- **`gtm-strategy.md`** — ⭐ **the canonical GTM strategy (v2)**. Synthesizes the
  research, the Activity OS expansion, and the adversarial roast into the current
  plan: solo-first wedge, $99–149 price test, registration-window watchlist,
  zero-friction second parent, split data model, decision gates, 90-day sequence.
  When docs disagree, this one wins.
- **`MVP-Ground-Zero.docx`** — the foundational strategy / positioning document
  (brand, voice, audience, the "why now"). Revised July 2026 with everything
  shipped since June (the family chief of staff) and **Section 12: Go-To-Market
  Strategy** — the team-facing summary of `gtm-strategy.md`.
- **`mvp-idea-roast.md`** — the 5-persona adversarial review of the strategy
  (Contrarian / Expansionist / First-Principles / Deep Researcher / Buyer +
  Judge). Verdict: RESHAPE — produced the v2 revisions. Full council transcripts
  in its appendix.
- **`gtm-research.md`** — the deep market-research report (July 2026): market
  sizing, competitive deep dive, the original wedge decision, ICP personas,
  pricing, the validation funnel, regulatory posture. *Superseded in part — see
  its header banner.*
- **`gtm-research-expansion.md`** — addendum generalizing the camp wedge into a
  year-round **Activity OS** (5 verticals) to solve seasonality. Survived the
  roast; incorporated into the strategy.
- **`ground-zero-critic-feedback.md`** — the Ground Zero doc pressure-tested through
  critical lenses (build discipline, etc.) to surface blind spots.
- **`ground-zero.py`** — generator that renders the Ground Zero `.docx` with the
  Hearth palette/voice (`python ground-zero.py`, needs `python-docx`).
