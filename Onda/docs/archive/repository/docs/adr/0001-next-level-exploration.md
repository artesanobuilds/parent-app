# 0001 — Isolate a parent-owned child-understanding experiment

Date: 2026-10-13. Status: proposed experiment, not approved launch decision.

## Context

Miguel and his former business partner have dismantled MVP as a joint venture. Independent continuation, IP/content rights and brand ownership are unresolved. The current repository is clean master at 5e5caca and includes October harness/voice work, so the September pivot context is historical rather than current architecture proof. The live beta contains real families and remains untouched.

The requested direction removes administrative breadth and explores conversation-first child understanding. Generic agents already provide chat and persistent memory; category competitors advertise family profiles and what-worked loops. Neither “neuroscience” nor remembering children demonstrates a defensible advantage.

## Proposed decision

Build a local, synthetic, parent-only experiment on isolated `next-level`. Test whether a parent-reviewed, evidence-attributed, changeable child-understanding notebook plus low-burden next steps outperforms a generic assistant with equivalent context. Include strengths, interests and child perspective, not only problems or compliance. Use selective manual export to explore portability before any connector implementation.

No hidden scores, diagnoses, child chatbot launch, administrative integration, existing content reuse, production migration, new credentials or deployment. No claim that a loop or profile is unique. Sign in with ChatGPT and plan-funded Responses access are an eligibility-dependent research option behind separate identity/usage boundaries, not a prerequisite.

## Consequences

This experiment can be rejected without touching beta families or the deployed product. Reuse is at the contract/design level until code audit and ownership review establish safe reuse. A launch decision requires task superiority, return usage, willingness-to-pay, expert safety review, commercial/auth eligibility and rights clearance. If portable notes alone deliver the value, ship a notebook or companion integration instead of another standalone app.
